# 주인공을 찾습니다 (Wanted: The Protagonist)

이세계 게이트에서 몬스터가 넘어오는 현대. 플레이어는 헌터 에이전시의 대표(에이전트)가 되어 헌터를 키우고 성장의 탑에 보냅니다. 에이전트는 남고, 헌터는 바뀝니다.

2D 턴제 로그라이크 · TypeScript + Phaser + Vite

## 플레이

- 웹 버전: https://sykim-6894.github.io/Log-of-SSS-Rank-Hunter/ (`main`에 머지되면 자동 배포)
- 조작: 방향키/WASD 이동·공격, Q 회전베기(마나 5), E 포션, Space 대기. 화면을 누르면 그쪽으로 한 칸 이동합니다.

## 지금 들어있는 것

- 본부: 헌터 정보, 등급(F~A, 전투력 기준), 에이전시 자금으로 훈련, 포션 상점(가끔 에이전트가 일부 지원)
- 성장의 탑 1~10층: 무작위 맵, 턴제 전투, 5층·10층 보스, 계단에서 올라가기/귀환 선택
- 귀환 시 계약 등급에 따라 상납, 승급하면 재계약과 아이템 지원금
- 사망 시 "넌 주인공이 아니었네...", 명예의 전당 기록 후 새 헌터 고용
- 헌터 슬롯 3개(세이브 슬롯처럼 전환), 빈 슬롯에 고용, 방출하면 경쟁 에이전시로 이동
- 헌터 순위: 우리 헌터·경쟁사 헌터·기록으로 남은 헌터·협회 랭커 10명을 함께 실시간 순위로. 1위 SSS, 2~4위 SS, 5~10위 S
- 사망 시 경쟁사가 스카웃할 확률(등급이 높을수록 높음), 한 번이라도 SSS였던 헌터는 무조건 스카웃. SSS 헌터의 최후는 "그래, 너였구나."
- 탑 2층부터 경쟁사 소속 옛 동료나 라이벌이 나타남. 쓰러뜨리면 무작위 보상 2개(아이템, 골드, 스킬, 위기 시 1회 지원) 또는 완전한 사망(경험치) 중 선택. 보내준 헌터는 더 강해져서 돌아옴
- 우리 헌터가 S급이 되면 경쟁사가 비슷한 전투력의 라이벌을 내세우고, 라이벌은 귀환할 때마다 함께 성장
- 브라우저에 자동 저장 (예전 세이브도 그대로 이어받음)

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 게임 규칙 테스트
npm run build    # dist/ 에 배포용 빌드
```

게임 규칙은 `src/core/`에 화면 코드와 분리되어 있고 `tests/`에서 테스트합니다. 화면은 `src/scenes/`에 있습니다.

소리는 음원 파일 없이 Web Audio로 그 자리에서 만들어 냅니다(`src/game/sfx.ts`: 효과음과 배경음악 4곡). 그래서 따로 표기할 음원 저작권이 없습니다. 화면 연출(색종이, 파편, 반짝임, 흔들림)은 `src/game/fx.ts`에 있습니다.
