# SSS급 헌터의 성장기 (과연 너일까)

이세계 게이트에서 몬스터가 넘어오는 현대. 플레이어는 헌터 에이전시의 대표(에이전트)가 되어 헌터를 키우고 성장의 탑에 보냅니다. 에이전트는 남고, 헌터는 바뀝니다.

2D 턴제 로그라이크 · TypeScript + Phaser + Vite

## 플레이

- 웹 버전: https://sykim-6894.github.io/log-of-sss-rank-hunter/ (`main`에 머지되면 자동 배포)
- 조작: 방향키/WASD 이동·공격, Q 회전베기(마나 5), E 포션, Space 대기. 화면을 누르면 그쪽으로 한 칸 이동합니다.

## 지금 들어있는 것 (2단계 프로토타입)

- 본부: 헌터 정보, 등급(F~A, 전투력 기준), 에이전시 자금으로 훈련, 포션 상점(가끔 에이전트가 일부 지원)
- 성장의 탑 1~10층: 무작위 맵, 턴제 전투, 5층·10층 보스, 계단에서 올라가기/귀환 선택
- 귀환 시 계약 등급에 따라 상납, 승급하면 재계약과 아이템 지원금
- 사망 시 "넌 주인공이 아니었네...", 명예의 전당 기록 후 새 헌터 고용
- 브라우저에 자동 저장

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 게임 규칙 테스트
npm run build    # dist/ 에 배포용 빌드
```

게임 규칙은 `src/core/`에 화면 코드와 분리되어 있고 `tests/`에서 테스트합니다. 화면은 `src/scenes/`에 있습니다.
